# 参考关节与高度目标对齐

2026-11-01，按用户要求调整 `Go2_Handstand_Config.py` 中的 `init_state.descire_joint_angles`，使直立参考姿态与基座 0.52 m、前脚 0.67 m 的奖励目标兼容。

## 修改依据

原参考后腿大腿角 2.25 rad、小腿角 −1.75 rad，在机身完全直立且后脚落地时，对应基座高度约 0.485 m。若保持原关节角而把基座抬到 0.52 m，后脚底会高出地面约 3.5 cm。因此原关节偏移惩罚与基座高度奖励存在几何目标冲突。

新参考角度由已对齐训练 URDF 的模型求逆运动学得到：基座固定为直立重力方向 `[-1,0,0]` 和 0.52 m 高度，前脚坐标原点高 0.67 m，两只后脚的球形碰撞体底部落地，整机质心的水平投影位于后脚支撑中心。左右腿对称，髋关节保持 0，前腿小腿角保持 −1.5 rad。搜索限定在训练使用的 90% 软关节限位内。

| 关节（左右相同） | 原参考角 rad | 新参考角 rad |
| --- | ---: | ---: |
| 前腿大腿 | 0.8 | 0.889690551738 |
| 后腿大腿 | 2.25 | 2.323561137691 |
| 后腿小腿 | −1.75 | −1.557252479414 |
| 四腿髋关节 | 0 | 0 |
| 前腿小腿 | −1.5 | −1.5 |

`descire_joint_angles` 是奖励目标，供 `default_pos` 和 `default_pos_reward` 使用；它不是动作零点。`default_joint_angles`、初始水平姿态与高度 0.42 m 保留原值，机器人仍从原始四足初始状态学习起立。观测 45/86 维、动作 12 维、23 项有效奖励的公式与权重、PD、动作缩放、命令范围和 PPO 参数均未改变。XML 无需修改，因为本次改变的是奖励参考，不是机器人结构或初始化动作零点。

## 验证

直接读取修改后的配置进行前向运动学计算，并调用参考环境的实际奖励函数：

- 基座高 0.52 m；两只前脚高 0.6700000000001 m；两只后脚底离地约 2.44e−14 m。
- 所有关节在软限位内；仅后脚与地面接触，没有额外自碰撞或穿地。
- `base_height` 原始分数为 1；`default_pos` 偏差惩罚为 0；`default_pos_reward` 为 1；直立方向误差为 0；`handstand_feet_height_exp` 约为 1。上述值未乘奖励权重和控制步长。
- 在双脚均分承重、零速度/零加速度的静态假设下，最大关节力矩约 11.012 N·m，低于小腿 35.55 N·m 上限；自由基座力矩/力残差小于 1e−9。补偿 PD 静态误差所需最大动作绝对值约 5.379，低于当前动作裁剪 100。
- AST 比较确认配置仅修改上述 6 个关节数值，其他配置不变。

本次消除的是高度目标与参考关节姿态的几何冲突，不是对训练收敛或动态步态效果的保证。该姿态是双脚静态支撑参考；步态接触奖励仍鼓励单脚支撑，运动中策略仍可偏离静态参考。训练域随机化、接触求解及单脚平衡需后续实际训练验证。本次没有启动训练。
