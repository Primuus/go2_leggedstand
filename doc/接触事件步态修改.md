# 接触事件步态修改

## 范围与参数

用户批准针对小碎步修改奖励结构。此次仅实现与验证，不追加训练。24项奖励权重保持（feet_air_time=1、contact=0.3、feet_clearance=2），PPO、资产、PD、速度上限0.5m/s、35%零速和关闭域随机化保持。

- 腾空结算：每脚clip((T-0.12)/0.12,-1,1)，落地求和后再限幅到[-1,1]，首次落地结算；短步有负分，支撑脚无持续扣分。保留RewardManager乘dt，过滤后40ms的短步现在单次扣约0.01333，原来约0.0016。正分只给满足下述有效交替条件的落地；未满足条件时正分归零，负分保留。
- 有效步：过滤后腾空至少0.12秒、至多0.36秒，峰值至少4cm，整个计入腾空段另一脚承重>50%体重，与上一有效步左右交替。初始任一腿均可；无效小抖步不推进交替记录。双支撑允许、行走时该项不奖励也不惩罚双支撑；零速保留原双脚接触奖励。
- contact：连续有效单支撑时长/0.12（封顶1）×高度质量（峰值/4cm封顶1）×过长衰减，并要求当前摆动脚>2cm、腿别符合交替。另一脚失去有效承重后，连续单支撑计时归零。
- feet_clearance：实际摆动脚相对6cm目标的三角评分，乘同样的连续支撑进度、交替和过长衰减。不再使用1.6秒相位，也不要求离地瞬间达到6cm；评分非负，落地/支撑脚不扣高度分。
- 0.24秒后单支撑过程分线性衰减，0.36秒归零；超过0.36秒落地无正分，避免一直单脚悬停。腾空计时饱和在0.38秒，所有会影响下一步奖励的历史状态均可观测。
- 行走/直立门控：非零运动命令、直立余弦>0.7、逐环境高度指数得分>0.7。三个步态项不再使用跨环境平均高度门控。其他来源奖励保持。零速/失去直立清除未完成步和交替历史；环境重置按env_ids清理。

接触采用Fz>1N及当前/上一帧OR过滤，T通常比未过滤诊断时长少20ms。以上阈值为本轮初始设计参数，尚未经新奖励训练验证，不保证已解决小碎步。

## 观测与部署

Actor由47变59，Critic由88变100。前45维基础观测不变，删除sin/cos两维，新增7对左右值：当前原始接触、过滤接触、腾空时长、连续单支撑时长、整段对侧有效承重标志、摆动峰值、上一有效迈步腿one-hot。时长除0.38、峰值除0.12；其余0/1，零速全部归零，不加观测噪声。镜像只交换每对左右值，不再反转周期相位。

GaitEvents为训练和MuJoCo共用实现，每控制步更新一次，重复读取观测/奖励不推进计时。训练用后脚传感器Fz、球形脚底高度；MuJoCo用相应脚碰撞几何、与地面的接触力。两者使用同一门控和参数；物理引擎接触响应本身仍可能有差异。

旧45/47策略继续按原观测回放；Isaac Lab评估旧47策略时显式重建旧相位，不把新接触标志当相位。固定时钟仅保留给旧策略和历史诊断，当前三项步态奖励及新策略输入不再依赖它。

## 检查点迁移

从最新完整model_4401.pt（47/88）迁移：保留所有原基础物理输入权重，丢弃两个时钟列，新增14列初始化为0；Critic保留38维尾部特权输入并移至新位置。Adam一阶/二阶矩按相同列映射，其他参数、优化器标量和累计迭代数保留。

迁移只能保证与旧策略“时钟两维置零”的输出一致，不能保证与原运动相位下输出一致；会记录删除时钟产生的输出差异。准备模型不是新训练结果，也不覆盖原model_4401.pt或其导出。

```bash
./ry_python.sh scripts/train_lab.py --headless --device cuda:0 --num_envs 64 \
  --resume logs/go2_handstand/2026-11-01_07-02-38_airtime_to4401/model_4401.pt \
  --migrate_events --prepare_only --run_name events_prepare
```

后续用户授权训练时，可从生成的59/100 prepared_model_4401.pt普通--resume，明确指定追加轮数，不再重复迁移。--migrate_events与普通--resume各自对应不同输入宽度，不自动猜测旧模型。
