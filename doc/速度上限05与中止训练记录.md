# 速度上限 0.5 m/s 与中止训练记录

用户批准：前向速度上限改为 0.5 m/s，从第 3600 轮继续训练 700 轮。

## 修改范围

- 行走命令均匀采样范围由 [0.1,0.35] 改为 [0.1,0.5] m/s；35% 全零命令、10 秒重采样、横向/转向零命令保持。
- 本地 MuJoCo 键盘前向上限读取同一配置，为 0.5 m/s；命令行超出上限会拒绝。此处是速度指令上限，不是对机器人实际速度的硬限幅。已运行的旧回放进程需要重新启动才能加载新配置。
- 保留 47/88 维观测、12 动作、显式相位、半周期镜像和实际步态诊断。
- 23 项奖励公式和权重保持第 3600 轮配置：抬脚目标 0.06 m，权重 2.0；不实施权重 15 或正负高度奖励。资产、PD、PPO 和域随机化保持。
- 直接 --resume 原 model_3600.pt，恢复模型、Adam、自适应学习率和迭代数；不使用 --migrate_phase。
- 评估入口增加可指定速度列表，便于在 0、0.2、0.5 m/s 下对照旧/新策略；评估无训练更新。

## 验证与结果

12 项本地回归通过，键盘上限/减速/清零检查通过；AST 对比确认训练配置唯一变化是 commands.ranges.lin_vel_x，奖励源文件与上轮逐字一致。服务器实际 64 环境预检通过，采样范围 [0.1,0.5]、47/88 观测、23 项奖励、固定资产与关节参数、10 次零动作步进及重置均通过。

预检目录 `2026-11-01_06-25-10_speed05_preflight`，没有 PPO 更新。正式训练目录 `2026-11-01_06-25-56_speed05_to4300`，从原 model_3600.pt 恢复，Adam 状态 17 项，自适应学习率恢复为 0.00038443359375；原计划本轮追加 700 次更新，实际按下文用户要求中止。

旧策略在 0.5 m/s MuJoCo 基线中于 4.34 秒首次触发失稳诊断。因而评估增加 upright_throughout 和 first_upright_failure_s，阈值仍采用此前分析使用的机身高度 <0.3 m 或直立余弦 <0.7。腾空/高度达标统计只取前 2 秒之后、首次失稳之前的窗口；若失败，窗口内的高抬脚不代表完成持续步态。位移和平均速度仍是完整仿真段统计，失败案例不得视作有效速度跟踪表现。

该修正仅影响评估统计，不修改训练奖励、终止或控制。首次未经失稳截断的本轮基线 JSON 保留，后续对照统一使用 bounded 结果。
